# LargeRDFBench

External reference data, used by `notebook/overview.py` to compare federated
SPARQL query execution time against BFC/SPECS's containment-check time.

- **Source**: Saleem, M., Hasnain, A., Ngonga Ngomo, A.-C. "LargeRDFBench: A
  billion triples benchmark for SPARQL endpoint federation." *Journal of Web
  Semantics* 48 (2018): 85–125. https://doi.org/10.1016/j.websem.2017.12.005
- **Repository**: https://github.com/dice-group/LargeRDFBench
- **This file**: `Results-final.xlsx`, the paper's own raw evaluation
  spreadsheet, linked from that repository's README:
  https://drive.google.com/file/d/0BzemFAUFXpqOOFl1a2RQV21LOW8/edit?usp=sharing.
  Copied here unmodified, for reproducibility of the numbers transcribed
  into `overview.py`.
